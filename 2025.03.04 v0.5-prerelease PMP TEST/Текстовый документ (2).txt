Новые/обновлённые функции:
- Image.draw(texture, x, y, [width], [height], [color], [srcx], [srcy], [srcw], [srch], [rotation], [alpha], [alMode], [GU_LINEAR]).

- Image.draweasy(texture, x, y, [color], [rotation], [alpha], [alMode], [GU_LINEAR])

GU_LINEAR - опциональное сглаживание для каждой текстуры, принимает true или false

- intraFont.print(x, y, text, [textColor], [font], [size], [textAngle])
- intraFont.printColumn(x, y, text, width, [textColor], [font], [size])

- intraFont.printUnderlined(x, y, text, [textColor], [lineColor], [font], [textSize])

- intraFont.printContoured(x, y, text, [textColor], [contourColor], [font], [textSize], [textAngle])

- intraFont.printBackground(x, y, text, [textColor], [bgColor], [font], [textSize])

- intraFont.printStriked(x, y, text, [textColor], [lineColor], [font], [textSize])

- intraFont.printShadowed(x, y, text, [textColor], [shadowColor], [font], [shadowAngle], [lightDistance], [textSize], [textAngle])

- intraFont.reverseText(text). Теперь функция не выводит развёрнутую строку, а только лишь возвращает её

- intraFont.printGradient(x, y, text, [textColorStart], [textColorEnd], [font], [textSize])

PMP.play(path, getPointer, [subtitlePath], [interruptButton], [FPS])

- getPointer (true/false) - получение указателя на видео, для вывода его через Image.draw() или Image.draweasy()
- subtitlePath - путь к субтитрам в формате .srt
- FPS - фпс воспроизводимого видео, нужно для корректного отображения сабов, по умолчанию 29.97

PMP.getFrame(pointer) - обновление кадра в указателе. Возвращает true при успешном обновлении при воспроизведении, nil во всех остальных случаях

PMP.stop(pointer) - остановка воспроизведения видео через указатель

PMP.getTimeCode() - возвращает таймкод, который сейчас воспроизводится

PMP.getSubs()  - возвращает строку субтитров для каждого конкретного таймкода

Таким образом, если вы просто хотите воспроизвести видео с субтитрами, то
PMP.play(path, false, 'subs.srt', buttons.interrupt, fps)
Готово всё сделать за вас.

Если же вам нужно кастомизировать вывод этого дела, то используйте следующую конструкцию:
framePointer = PMP.play(path, true, 'subs.srt', nil, fps)

while true do
    ...
    ...
    if PMP.getFrame(framePointer) then
        Image.draw(framePointer, x, y)
        intraFont.print(x, y, PMP.getSubs())
    end
    ...
    ...
end

PMP.stop(framePointer)
